조사일: 2026-09-02 / 조사자: 자동 수집기 + 육안 대조

## 1. 전기위원회 (korec.go.kr)

### 1.1 게시판 접근 규격

| 항목 | 값 |
|---|---|
| 위원회 개최결과 목록 | `POST /notice/result/selectNoticeList.do` (`bbsSe=2`) |
| 공지사항 목록 | `POST /notice/selectNoticeList.do` (`bbsSe=1`) |
| 상세 | `POST /notice[/result]/moveNoticeDetail.do` (`bbsSntncNo`, `bbsSe`) |
| 첨부 다운로드 | `POST /commonfile/fileDownLoad.do?attachingFilePath=&attachingFileNm=` |
| 페이지 이동 | 폼 필드 `pageIndex` (개최결과 10건/쪽, 공지사항 15건/쪽) |
| robots | `Allow: /`, `Disallow: /search.do` — 대상 게시판 수집 허용 |

**함정**: 루트 요청에 `Accept: text/html`이 없으면 HTML이 아니라 배너 JSON이 반환된다.
수집기는 항상 HTML Accept 헤더를 보낸다.

**이점**: 목록 페이지의 hidden input에 `filePath`/`fileName`이 그대로 노출되어,
상세 페이지를 거치지 않고 대표 첨부를 바로 내려받을 수 있다.
(단일 게시글에 첨부가 여러 개인 경우는 상세 페이지 확인이 필요하다 — 미확인)

### 1.3 첨부파일 포맷 분포 (최근 5년, 183건)

| 확장자 | 건수 | 비중 |
|---|---:|---:|
| `.hwp` | 115 | 63% |
| `.pdf` | 48 | 26% |
| `.hwpx` | 18 | 10% |
| `.png` | 2 | 1% |

**HWP 계열이 73%**로 지침의 PDF 파이프라인만으로는 부족하다. 처리 경로:

- `.hwp` → 설치된 한컴오피스를 COM(`HWPFrame.HwpObject`)으로 구동해 PDF 변환 후
  기존 PDF 파이프라인 재사용 (표 구조 보존에 유리)
- `.hwpx` → OWPML(ZIP+XML) 직접 파싱 (`python-hwpx`)

### 1.4 문서 유형별 확보 가능 칼럼

#### (가) 위원회 개최결과 — 예: 제327차 (4쪽, PDF, 텍스트 추출 가능)

구조: `회의 개요` → `회의 결과(총 N건)` → `심의 내용`(안건유형별 번호 목록 + `※ (사유)`)
→ `차기 위원회 개최 계획`

확보 가능: 전기위원회회차, **개최일**, 안건명, 안건유형, 결정결과, 결정사유(요약),
조건부 허가의 계통보강 예정시점

확보 **불가**: 사업주체, 최대주주, 설비용량, 총사업비, 상세 주소, 계통계약 정보

추출 시 주의:
- 표지 제목이 굵게 처리를 위해 **동일 문자가 17회 중복 렌더링**된다 → 중복 제거 필요
- `일시`/`장소`/`참석위원` **레이블이 이미지로 삽입**되어 텍스트 추출에서 누락된다.
  값(`\`26. 8. 14.`, `14:00`)은 추출되므로 위치 기준으로 매핑하되 OCR 대조 대상이다.
- **게시일(2026-08-19) ≠ 개최일(2026-08-14)** — 지침 §22 위반 방지의 핵심 지점

제327차 전남·광주 관련 안건 (원문 확인):
| 안건 | 유형 | 지역 | 발전원 표기 |
|---|---|---|---|
| 신안 그린쏠라발전 1단지 | 준비기간·공사계획인가기간 연장 | 신안군 | 명시 없음 → 검수필요 |
| 영광 야월 해상풍력 | 준비기간·공사계획인가기간 연장 | 영광군 | 해상풍력 |
| 곡성 천지에너지풍력 | 주식취득 인가 | 곡성군 | 풍력(육상/해상 미표기) → 검수필요 |
| 영암 시종그린 태양광 1호 | **조건부 허가** | 영암군 | 태양광 |
| 밝은해남태양광 2호 | **조건부 허가** | 해남군 | 태양광 |
| 전남테크노파크 풍력시스템평가센터 | 허가 **미**취소 | 전남 | 풍력 → 검수필요 |
| 광주 연료전지 | 준비기간 연장 | 광주 | 연료전지 → **대상 제외** |

조건부 허가 2건의 사유는 모두 `계통 보강(\`34. 10월 예정) 이후 연계가능`이다.
지침 §14에 따라 이는 **계통계약 체결이 아니라 허가조건·계통제약 정보**로 기록한다.

#### (나) 3MW 초과 발전사업 허가대장 — 2026년 2분기판 (834쪽, PDF, 표 추출 가능)

표 칼럼: `NO | 상호(사업자) | 발전소 위치 | 원동력 | 용량(MW) | 허가및변경일 | 사업준비기간 | 기타(변경사항)`

2001년부터의 전체 허가 이력을 담은 **최초허가일 확보의 핵심 소스**.

문서 자체 안내에 따른 판독 규칙:
- `기타(변경사항)`란이 **빈칸이면 최초 허가일**, 내용이 있으면 그 변경에 대한 허가증 재교부
- TypeA(연도 생략 허가번호) / TypeB(연도 포함 허가번호) 두 양식이 혼재
- 문서 말미에 "작성상 작은 오류가 있을 수 있음" 명시 → 출처 우선순위 4위(지침 §4)

표준화 필요: 용량 표기가 `45만kw×2` 형태로 비정형, 허가일이 `‘01.11.1` 형태

#### (다) 전기위원회 회의록 — 예: 제326차 (2.1MB PDF)

개최결과보다 상세하며 최대주주·사업주체·심의 상세가 포함될 것으로 예상. 구조 분석 예정.

#### (라) 허가취소 처분 공고 (공지사항)

최근 5년 27건. 허가취소·청문 실시 공고가 별도 게시된다.
지침 §13에 따라 취소 사업도 삭제하지 않고 `사업상태`로 구분한다.
